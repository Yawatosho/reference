# THE REFERENCE INTERVIEW GAME — ほんとの質問

**聞くことから、レファレンスは始まる。**

利用者との会話を通して、本当に知りたいことを見つけるレファレンス・インタビューゲームです。

## ゲームをプレイ

### [「ほんとの質問」を始める](https://yawatosho.github.io/reference/)

ブラウザだけで遊べます。ダウンロードやアカウント登録は必要ありません。

## どんなゲーム？

あなたは大学図書館の司書さんです。

カウンターを訪れる利用者の相談は、少し曖昧だったり、話が思いがけない方向へ進んだりします。限られた回数のなかで質問を選び、会話から利用者の「ほんとの質問」を整理してください。

ときには相談と関係のない雑談が、会話の雰囲気をやわらかくすることもあります。正解だけを急がず、相手の言葉に耳を傾けることも、このゲームの楽しみ方のひとつです。

## 遊び方

1. ケースを選ぶと、利用者とのインタビューが始まります。
2. 表示された候補から、聞きたい質問を選びます。
3. 質問できるのは基本6回です。途中でも回答をまとめられます。
4. 会話を読み返しながら、4つの文節を選んで利用者の質問を一文にします。
5. 回答内容に応じて得点とランクが表示されます。質問回数そのものは得点に影響しません。

ケースをクリアすると、新しい相談が順番に解放されます。通常の10ケースをすべて終えると、いつもとは立場の異なるエクストラケースも遊べます。

## セーブについて

クリア状況、ケースごとのベストスコア、音声のON／OFF設定は、使用中のブラウザに自動保存されます。

別のブラウザや端末には引き継がれません。ブラウザの保存データを削除すると、ゲームの進行状況もリセットされます。

## 音声について

ゲームにはBGMとメッセージ音があります。画面の「SOUND」ボタンから、いつでもON／OFFを切り替えられます。

## 対応環境

PC・スマートフォンのブラウザに対応しています。快適に遊ぶため、Safari、Chrome、Edge、Firefoxなどの最新版をご利用ください。

## アクセス解析とプライバシー

利用状況の把握と改善のため、Google Analyticsを使用しています。

アクセスした画面などの匿名の利用状況を計測しますが、回答内容、インタビューの会話内容、個人を特定する情報は送信しません。ゲームの進行状況は、お使いのブラウザ内にのみ保存されます。
